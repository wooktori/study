## 1. 객체 vs Map — 연관 배열로 사용할 때 차이

| 구분 | 객체 (`{}`) | `Map` |
|---|---|---|
| 키 타입 | 문자열, Symbol만 | 모든 타입 가능 |
| 순서 보장 | ❌ (ES2015 이후 삽입 순서 보장되나 비권장) | ✅ 삽입 순서 보장 |
| 크기 확인 | `Object.keys(obj).length` | `map.size` |
| 이터러블 | ❌ (직접 변환 필요) | ✅ `for...of` 바로 가능 |
| 프로토타입 오염 | ⚠️ 있음 | ✅ 없음 |
| 성능 | 키/값 적을 때 유리 | 키/값 많고 잦은 추가/삭제 시 유리 |

```js
// 객체 — 키가 문자열로 강제 변환됨
const obj = {};
obj[1] = "a";
obj[true] = "b";
console.log(Object.keys(obj)); // ["1", "true"] — 문자열로 변환됨

// Map — 키 타입 유지
const map = new Map();
map.set(1, "a");
map.set(true, "b");
map.set({ id: 1 }, "c"); // 객체도 키로 사용 가능
console.log(map.size); // 3
```

> **언제 Map을 쓸까?**
> - 키가 문자열이 아닌 경우
> - 자주 추가/삭제가 일어나는 경우
> - 순서가 중요한 경우
> - 프로토타입 오염을 피해야 하는 경우

## 2. 계산된 속성명 활용

대괄호 안에 표현식을 넣어 **동적으로 속성명을 결정**하는 기법이다.

```js
// 기본 사용
const key = "name";
const obj = { [key]: "철수" };
console.log(obj.name); // "철수"

// 표현식 사용
const prefix = "get";
const obj2 = {
  [`${prefix}Name`]() { return "철수"; },
  [`${prefix}Age`]()  { return 20; },
};
console.log(obj2.getName()); // "철수"

// 실무 활용 — 폼 상태 관리
function handleChange(field, value) {
  setState(prev => ({ ...prev, [field]: value }));
}
handleChange("email", "test@test.com");
// { email: "test@test.com" }

// 실무 활용 — 에러 메시지 맵
const ERROR = { NOT_FOUND: "NOT_FOUND", UNAUTHORIZED: "UNAUTHORIZED" };
const messages = {
  [ERROR.NOT_FOUND]: "페이지를 찾을 수 없습니다.",
  [ERROR.UNAUTHORIZED]: "로그인이 필요합니다.",
};
```

## 3. 대괄호 표기법 — 사용 시점과 따옴표 생략

### 대괄호 표기법을 써야 하는 경우

```js
// 1. 키가 변수일 때
const key = "name";
console.log(obj[key]); // ✅
console.log(obj.key);  // ❌ "key"라는 속성을 찾음

// 2. 키에 특수문자/공백이 있을 때
const obj = { "my-key": 1, "hello world": 2 };
console.log(obj["my-key"]);     // ✅
console.log(obj["hello world"]); // ✅
console.log(obj.my-key);        // ❌ SyntaxError

// 3. 키가 숫자로 시작할 때
const obj2 = { "1st": "first" };
console.log(obj2["1st"]); // ✅
console.log(obj2.1st);    // ❌ SyntaxError

// 4. 키가 예약어일 때 (구버전 환경)
const obj3 = { "class": "container" };
console.log(obj3["class"]); // ✅
```

### 헷갈리는 예시

```js
const a = { b: { c: 42 } };
const key = "c";

console.log(a.b.c);     // 42 ✅
console.log(a.b[key]);  // 42 ✅ — key 변수 값 "c"를 사용
console.log(a.b["c"]);  // 42 ✅ — 문자열 "c" 직접 사용
console.log(a["b"][key]); // 42 ✅

// 함정
console.log(a["b"]["key"]); // undefined ❌ — "key"라는 속성 없음
```

### 따옴표를 생략할 수 있는 경우

대괄호 안의 값이 **변수나 표현식**이면 따옴표 없이 쓴다.

```js
const key = "name";

obj[key]    // ✅ 변수 — 따옴표 없음
obj["name"] // ✅ 문자열 리터럴 — 따옴표 있음
obj[0]      // ✅ 숫자 리터럴 — 따옴표 없음 (내부적으로 "0"으로 변환)
obj["0"]    // ✅ 위와 동일
```

## 4. 존재하지 않는 속성에 접근하면?

```js
const obj = { name: "철수" };

// 1단계 접근 — undefined 반환
console.log(obj.age); // undefined

// 2단계 이상 접근 — TypeError 발생
console.log(obj.age.value); // ❌ TypeError: Cannot read properties of undefined

// 안전하게 접근하는 방법
console.log(obj.age?.value);       // undefined (옵셔널 체이닝)
console.log(obj.age ?? "기본값");  // "기본값" (널 병합 연산자)
```

## 5. 객체 동결 — freeze와 완전한 불변 객체

### Object.freeze() 이점

```js
const config = Object.freeze({
  API_URL: "https://api.example.com",
  TIMEOUT: 3000,
});

config.API_URL = "https://hack.com"; // 무시됨 (strict mode에서 TypeError)
config.NEW_KEY = "value";            // 무시됨
delete config.TIMEOUT;               // 무시됨

console.log(config.API_URL); // "https://api.example.com" — 변경 안 됨
```

> **이점:** 상수 설정값, 액션 타입, 열거형 상수 등에서 실수로 인한 변경 방지

### 문제점 — 얕은 동결

```js
const obj = Object.freeze({
  name: "철수",
  address: { city: "서울" }, // 중첩 객체는 동결 안 됨
});

obj.name = "영희";           // 무시됨 ✅
obj.address.city = "부산";   // 변경됨 ❌

console.log(obj.address.city); // "부산"
```

### 완전한 불변 객체 만들기 — 깊은 동결

```js
function deepFreeze(obj) {
  Object.keys(obj).forEach(key => {
    if (typeof obj[key] === "object" && obj[key] !== null) {
      deepFreeze(obj[key]);
    }
  });
  return Object.freeze(obj);
}

const obj = deepFreeze({
  name: "철수",
  address: { city: "서울" },
});

obj.address.city = "부산"; // 무시됨 ✅
console.log(obj.address.city); // "서울"
```

## 6. 깊은 복사 방법들

### 방법 비교

| 방법 | 깊은 복사 | 함수 | undefined | Date | 순환 참조 |
|---|---|---|---|---|---|
| `{...obj}` | ❌ 얕은 복사 | ✅ | ✅ | ❌ | ❌ |
| `JSON.parse/stringify` | ✅ | ❌ 사라짐 | ❌ 사라짐 | ❌ 문자열 변환 | ❌ 에러 |
| `structuredClone` | ✅ | ❌ 에러 | ✅ | ✅ | ✅ |
| 재귀 직접 구현 | ✅ | 설정 가능 | 설정 가능 | 설정 가능 | 설정 가능 |

```js
const original = {
  name: "철수",
  scores: [1, 2, 3],
  info: { age: 20 },
};

// 1. 전개 구문 — 얕은 복사
const shallow = { ...original };
shallow.info.age = 99;
console.log(original.info.age); // 99 — 참조 공유됨 ❌

// 2. JSON.parse/stringify — 간단하지만 제한 있음
const deep1 = JSON.parse(JSON.stringify(original));
deep1.info.age = 99;
console.log(original.info.age); // 20 — 독립적 ✅

// 3. structuredClone — 권장 (ES2022)
const deep2 = structuredClone(original);
deep2.info.age = 99;
console.log(original.info.age); // 20 ✅
```

### JSON.parse/stringify 문제점

```js
const obj = {
  fn: () => "hello",     // ❌ 사라짐
  undef: undefined,      // ❌ 사라짐
  date: new Date(),      // ❌ 문자열로 변환
  nan: NaN,              // ❌ null로 변환
  reg: /regex/,          // ❌ {} 로 변환
};

const copied = JSON.parse(JSON.stringify(obj));
console.log(copied);
// { date: "2026-...", nan: null, reg: {} }
// fn, undef 는 아예 없음
```

## 7. 순환 참조가 있는 객체 복사

```js
const obj = { name: "철수" };
obj.self = obj; // 순환 참조

// JSON.stringify — 에러
JSON.stringify(obj); // ❌ TypeError: Converting circular structure to JSON

// structuredClone — 처리 가능
const copied = structuredClone(obj); // ✅

// 직접 구현 — WeakMap으로 순환 참조 추적
function deepCopy(obj, visited = new WeakMap()) {
  if (obj === null || typeof obj !== "object") return obj;
  if (visited.has(obj)) return visited.get(obj); // 순환 참조 감지

  const copy = Array.isArray(obj) ? [] : {};
  visited.set(obj, copy);

  for (const key of Object.keys(obj)) {
    copy[key] = deepCopy(obj[key], visited);
  }
  return copy;
}
```

## 8. 전개 구문 유의점

```js
// 1. 얕은 복사만 된다
const a = { x: { y: 1 } };
const b = { ...a };
b.x.y = 99;
console.log(a.x.y); // 99 — 참조 공유됨 ⚠️

// 2. 뒤에 오는 값이 덮어씀
const defaults = { color: "red", size: 10 };
const custom = { size: 20 };
const result = { ...defaults, ...custom };
console.log(result); // { color: "red", size: 20 }

// 3. 배열에도 사용 가능
const arr1 = [1, 2, 3];
const arr2 = [...arr1, 4, 5]; // [1, 2, 3, 4, 5]

// 4. 이터러블하지 않으면 에러
const str = "hello";
console.log([...str]); // ["h", "e", "l", "l", "o"] ✅

const num = 42;
console.log([...num]); // ❌ TypeError: num is not iterable
```

## 9. 구조 분해 할당 — 중첩 속성 접근

```js
const user = {
  name: "철수",
  address: {
    city: "서울",
    zip: "12345",
  },
  scores: [90, 85, 92],
};

// 중첩 구조 분해
const { name, address: { city, zip } } = user;
console.log(name); // "철수"
console.log(city); // "서울"
// ⚠️ address 변수는 생성되지 않음

// 기본값 설정
const { age = 20, address: { country = "한국" } } = user;
console.log(age);     // 20
console.log(country); // "한국"

// 별칭(rename)
const { name: userName, address: { city: userCity } } = user;
console.log(userName); // "철수"
console.log(userCity); // "서울"

// 배열 구조 분해
const [first, , third] = user.scores; // 두 번째 건너뜀
console.log(first); // 90
console.log(third); // 92

// 함수 파라미터에서 활용
function greet({ name, address: { city } }) {
  return `${name}님, ${city}에서 오셨군요.`;
}
console.log(greet(user)); // "철수님, 서울에서 오셨군요."
```

## 10. Symbol — 사용 시점과 JSON.stringify 처리

### Symbol 사용 시점

```js
// 1. 유일한 객체 키 — 외부 라이브러리와 키 충돌 방지
const MY_KEY = Symbol("myKey");
const obj = { [MY_KEY]: "내부 데이터" };

// 2. 상수 열거형 대체
const Status = Object.freeze({
  PENDING: Symbol("PENDING"),
  DONE: Symbol("DONE"),
  ERROR: Symbol("ERROR"),
});

if (state === Status.PENDING) { /* ... */ }

// 3. Well-known Symbol — 내장 동작 커스터마이징
class Range {
  constructor(start, end) {
    this.start = start;
    this.end = end;
  }
  [Symbol.iterator]() {
    let current = this.start;
    const end = this.end;
    return {
      next() {
        return current <= end
          ? { value: current++, done: false }
          : { done: true };
      }
    };
  }
}

for (const n of new Range(1, 5)) {
  console.log(n); // 1, 2, 3, 4, 5
}
```

### Symbol과 JSON.stringify

```js
const id = Symbol("id");
const obj = {
  name: "철수",
  [id]: 12345,          // Symbol 키
  fn: () => "hello",    // 함수
};

console.log(JSON.stringify(obj));
// {"name":"철수"}
// Symbol 키 속성과 함수는 제외됨

// Symbol 속성을 직렬화하려면 직접 처리
const result = {
  ...obj,
  id: obj[id], // Symbol 키 값을 일반 키로 복사
};
console.log(JSON.stringify(result)); // {"name":"철수","id":12345}
```

## 11. 이터러블 객체란?

`Symbol.iterator` 메서드를 가진 객체로, `for...of`, 전개 구문, 구조 분해 할당 등에서 사용 가능하다.

```js
// 기본 이터러블: Array, String, Map, Set, arguments

// 일반 객체는 이터러블이 아님
const obj = { a: 1, b: 2 };
for (const x of obj) {} // ❌ TypeError: obj is not iterable

// 이터러블로 만들기
const iterable = {
  data: [1, 2, 3],
  [Symbol.iterator]() {
    let index = 0;
    return {
      next: () =>
        index < this.data.length
          ? { value: this.data[index++], done: false }
          : { done: true },
    };
  },
};

for (const val of iterable) {
  console.log(val); // 1, 2, 3
}

console.log([...iterable]); // [1, 2, 3]
```

## 12. 이터레이터와 제너레이터 실무 활용

### 이터레이터

```js
// 이터레이터 프로토콜 — next()를 가진 객체
function range(start, end) {
  return {
    [Symbol.iterator]() {
      let current = start;
      return {
        next() {
          return current <= end
            ? { value: current++, done: false }
            : { value: undefined, done: true };
        }
      };
    }
  };
}

console.log([...range(1, 5)]); // [1, 2, 3, 4, 5]
```

### 제너레이터

`function*`으로 선언하고 `yield`로 값을 하나씩 반환한다.

```js
function* range(start, end) {
  for (let i = start; i <= end; i++) {
    yield i;
  }
}

console.log([...range(1, 5)]); // [1, 2, 3, 4, 5]
```

### throw와 return 메서드

```js
function* gen() {
  try {
    yield 1;
    yield 2;
    yield 3;
  } catch (e) {
    console.log("에러:", e.message);
    yield 99;
  }
}

const g = gen();
console.log(g.next());          // { value: 1, done: false }
console.log(g.throw(new Error("오류"))); // 에러: 오류, { value: 99, done: false }
console.log(g.next());          // { value: undefined, done: true }

// return — 즉시 종료
function* gen2() {
  yield 1;
  yield 2;
  yield 3;
}
const g2 = gen2();
console.log(g2.next());        // { value: 1, done: false }
console.log(g2.return("끝")); // { value: "끝", done: true }
console.log(g2.next());        // { value: undefined, done: true }
```

### 실무 활용

```js
// 1. 무한 시퀀스 (페이지네이션 ID 생성 등)
function* idGenerator() {
  let id = 1;
  while (true) yield id++;
}
const nextId = idGenerator();
console.log(nextId.next().value); // 1
console.log(nextId.next().value); // 2

// 2. 비동기 흐름 제어 (redux-saga)
function* fetchUser(id) {
  const user = yield fetch(`/api/users/${id}`);
  const posts = yield fetch(`/api/users/${id}/posts`);
  return { user, posts };
}

// 3. 지연 평가 — 필요한 만큼만 계산
function* lazyMap(iterable, fn) {
  for (const item of iterable) {
    yield fn(item);
  }
}
```

## 13. 메모리 누수와 WeakMap

### 메모리 누수가 발생하는 상황

```js
// Map을 사용한 경우 — 객체가 제거되어도 참조가 남아 GC 불가
const cache = new Map();

function process(element) {
  cache.set(element, "데이터"); // element가 DOM에서 제거되어도 Map에 남음
}

// DOM 요소 제거 후에도 cache에 참조가 남아 메모리 해제 안 됨
document.body.removeChild(element);
// element는 여전히 cache에 있어서 GC 대상이 아님 ❌
```

### WeakMap으로 해결

```js
// WeakMap — 키가 약한 참조, GC 대상이 될 수 있음
const cache = new WeakMap();

function process(element) {
  cache.set(element, "데이터");
}

// DOM 요소 제거 시 WeakMap에서도 자동으로 GC됨
document.body.removeChild(element);
// element에 대한 다른 참조가 없으면 GC 대상이 됨 ✅
```

### Map vs WeakMap 비교

| 구분 | `Map` | `WeakMap` |
|---|---|---|
| 키 타입 | 모든 타입 | 객체만 가능 |
| GC 영향 | ❌ 참조 유지 | ✅ 약한 참조 (GC 가능) |
| 이터러블 | ✅ | ❌ |
| size 확인 | ✅ | ❌ |
| 주요 용도 | 일반 데이터 저장 | DOM 관련 데이터, 캐시 |

```js
// 실무 활용 — 컴포넌트별 상태 저장 (메모리 누수 없이)
const stateMap = new WeakMap();

function getState(component) {
  if (!stateMap.has(component)) {
    stateMap.set(component, { count: 0 });
  }
  return stateMap.get(component);
}

// component가 제거되면 stateMap에서도 자동으로 GC됨
```
