## 1. 메모이제이션이란? 리액트에서 어떻게 구현하는지?

**메모이제이션(Memoization)** 이란 이전에 계산한 결과를 캐싱해두고, 같은 입력이 들어오면 다시 계산하지 않고 캐시된 결과를 반환하는 최적화 기법이다.

리액트는 세 가지 방법으로 메모이제이션을 제공한다.

| API | 대상 | 목적 |
|---|---|---|
| `React.memo()` | 컴포넌트 | props가 같으면 리렌더링 건너뜀 |
| `useMemo()` | 계산된 값 | 의존성이 같으면 재계산 건너뜀 |
| `useCallback()` | 함수 | 의존성이 같으면 함수 재생성 건너뜀 |

## 2. useMemo 훅이란? 유용한 경우와 흔한 실수

**계산 비용이 큰 값을 캐싱하는 훅**이다. 의존성이 바뀔 때만 재계산한다.

```jsx
const cachedValue = useMemo(() => computeExpensiveValue(a, b), [a, b]);
```

### 유용한 경우

```jsx
// 1. 비용이 큰 계산
const sortedList = useMemo(() => {
  return list.sort((a, b) => a.price - b.price); // 정렬은 O(n log n)
}, [list]);

// 2. React.memo와 함께 — 자식에게 객체를 props로 전달할 때
const style = useMemo(() => ({ color: theme, fontSize: size }), [theme, size]);
// 객체를 매 렌더링마다 새로 만들면 React.memo가 무효화됨

// 3. useEffect 의존성으로 객체/배열을 넘길 때
const options = useMemo(() => ({ id, type: "user" }), [id]);
useEffect(() => { fetchData(options); }, [options]);
```

### 흔히 저지르는 실수

```jsx
// ❌ 단순 계산에 useMemo 남용 — 오히려 오버헤드
const double = useMemo(() => count * 2, [count]); // 그냥 count * 2 쓰면 됨

// ❌ 의존성 누락 — 잘못된 캐시값 반환
const result = useMemo(() => compute(a, b), [a]); // b가 빠짐

// ❌ 모든 값에 useMemo — 코드만 복잡해지고 성능 이득 없음
// 먼저 프로파일링으로 병목을 확인한 후 적용해야 함
```

## 3. useMemo 대신 useCallback을 사용해야 하는 경우

**useMemo는 값을 캐싱하고, useCallback은 함수를 캐싱한다.** 반환하는 대상이 함수일 때는 `useCallback`이 더 명확하다.

```jsx
// useMemo로 함수 캐싱 — 가능하지만 불명확
const handleClick = useMemo(() => () => doSomething(id), [id]);

// ✅ useCallback — 함수 캐싱의 명시적인 방법
const handleClick = useCallback(() => doSomething(id), [id]);
```

`useCallback(fn, deps)`은 `useMemo(() => fn, deps)`와 동일하다.

### useCallback이 필요한 주요 상황

```jsx
// 1. React.memo로 감싼 자식에게 이벤트 핸들러를 전달할 때
const Child = React.memo(({ onClick }) => <button onClick={onClick}>클릭</button>);

function Parent() {
  const handleClick = useCallback(() => {
    doSomething();
  }, []); // 의존성이 없으면 항상 같은 함수 참조

  return <Child onClick={handleClick} />; // React.memo 효과가 살아있음
}

// 2. 커스텀 훅에서 반환하는 함수
function useCounter() {
  const [count, setCount] = useState(0);
  const increment = useCallback(() => setCount(c => c + 1), []);
  return { count, increment }; // increment가 안정적 참조를 가짐
}
```

> **정리:** `useMemo`는 계산 비용이 큰 값, `useCallback`은 함수를 캐싱한다. 남용하면 코드가 복잡해지므로 프로파일링 후 실제 병목에만 적용한다.
