## 1. 훅이란?

**함수형 컴포넌트에서 상태(state)와 사이드이펙트(side effect) 등 리액트 기능을 사용할 수 있게 해주는 함수**다. 이름이 항상 `use`로 시작하는 것이 규칙이다.

```jsx
// 훅 사용 예시
function Counter() {
  const [count, setCount] = useState(0); // 상태 훅
  useEffect(() => { document.title = count; }, [count]); // 이펙트 훅

  return <button onClick={() => setCount(count + 1)}>{count}</button>;
}
```

## 2. 훅의 도입 배경

React 16.8(2019) 이전에는 클래스형 컴포넌트를 써야만 상태와 생명주기를 다룰 수 있었다. 이 방식에는 세 가지 문제가 있었다.

| 문제 | 설명 |
|---|---|
| 로직 재사용 어려움 | 상태 로직을 컴포넌트 간에 공유하려면 HOC나 render props 같은 복잡한 패턴이 필요했다 |
| 거대한 컴포넌트 | 생명주기 메서드(`componentDidMount`, `componentDidUpdate` 등)에 서로 관계없는 로직이 뒤섞였다 |
| `this` 혼란 | 클래스의 `this` 바인딩은 JavaScript 초보자뿐 아니라 숙련자에게도 혼란을 줬다 |

훅은 이 세 문제를 모두 해결한다. 상태 로직을 커스텀 훅으로 분리해 재사용하고, 연관된 로직을 하나의 `useEffect`로 묶으며, `this` 없이 함수만으로 모든 기능을 구현할 수 있다.

## 3. 훅의 사용 규칙

훅은 두 가지 규칙을 반드시 지켜야 한다.

### 1. 최상위에서만 호출한다

반복문, 조건문, 중첩 함수 안에서 훅을 호출하면 안 된다. 리액트는 훅의 호출 순서로 상태를 식별하기 때문에, 순서가 바뀌면 버그가 발생한다.

```jsx
// ❌ 조건문 안에서 훅 호출 — 호출 순서가 달라질 수 있음
function Component({ isLoggedIn }) {
  if (isLoggedIn) {
    const [name, setName] = useState(""); // 조건부 훅 ❌
  }
}

// ✅ 훅은 항상 최상위에서 호출
function Component({ isLoggedIn }) {
  const [name, setName] = useState(""); // 최상위 ✅
  if (!isLoggedIn) return null;
  return <p>{name}</p>;
}
```

### 2. 리액트 함수 안에서만 호출한다

일반 JavaScript 함수에서는 훅을 사용할 수 없다. 함수형 컴포넌트 또는 사용자 정의 훅 안에서만 호출해야 한다.

```jsx
// ❌ 일반 함수에서 호출
function fetchData() {
  const [data, setData] = useState(null); // ❌
}

// ✅ 커스텀 훅(use로 시작)에서는 사용 가능
function useFetchData(url) {
  const [data, setData] = useState(null); // ✅
  useEffect(() => { /* ... */ }, [url]);
  return data;
}
```

## 4. 클래스 컴포넌트에서 훅을 사용할 수 없나?

**사용할 수 없다.** 훅은 함수형 컴포넌트 전용이다. 클래스 컴포넌트에서 훅을 호출하면 에러가 발생한다.

클래스 컴포넌트에서는 대신 `this.state`, `this.setState()`, `componentDidMount()` 등 클래스 API를 사용한다. 클래스 컴포넌트와 함수형 컴포넌트는 한 프로젝트 안에서 공존할 수 있으므로, 기존 클래스 컴포넌트를 모두 마이그레이션할 필요는 없다.

> **정리:** 훅은 함수형 컴포넌트에서 상태와 사이드이펙트를 다루는 함수다. 클래스형의 복잡성을 해소하기 위해 도입됐으며, 최상위 호출과 리액트 함수 내 호출이라는 두 가지 규칙을 따른다. 클래스 컴포넌트에서는 사용 불가하다.
